# Experiment 01 - Kanban Board using Jira

## Objective
Create a Kanban Board to visualize project tasks.

## Tool Used
- Jira Software

## Procedure
1. Created a Kanban project.
2. Added To Do, In Progress, and Done columns.
3. Added five sample tasks.
4. Moved tasks between the columns to simulate the workflow.

## Sample Tasks
- Prepare Project Documentation
- Design Login Page
- Develop User Registration Module
- Write Test Cases
- Deploy Website

## Result
Successfully created a Kanban board and simulated task movement using Jira.
